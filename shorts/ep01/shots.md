# EP 1 — Shot prompts (image-to-video, 9:16)

Tools: Kling / Veo / Runway. Generate each clip from the **start frame** = the character reference(s) from `characters.md` (or a still you generate first with the same prompt), then animate with the prompt.

**Clip lengths:** most tools output 5–10 s. Generate **5 s** (or the tool's minimum) and **trim to the target duration** in the edit. Turn **generated audio off** (voices and SFX are added in the edit).
**Lip-sync:** characters who speak on screen are cut so mouths are mostly hidden or off-axis. If your tool has a lip-sync feature, run it with your recorded take; otherwise cover with the cutaways noted.

**Global style (append to every prompt):**
`vertical 9:16, photorealistic cinematic realism, handheld documentary feel, natural skin texture, shallow depth of field, subtle film grain, Casablanca Morocco. No text, no logos, no brand names, no signage, no watermark.`
**Negative (if the tool has the field):** `text, letters, logos, watermark, subtitles, cartoon, distorted hands, extra fingers`

Timecodes map to the script (`script.md`). Shots are split into clips that match the cuts in `edit_guide.md`.

## Re-roll checklist
- Face drift? Re-attach the reference and paste the TAG exactly.
- Any text or logo appeared? Re-roll; do **not** try to remove it in the edit.
- Too long? Trim; too short? Freeze the last frame (CapCut `Freeze`).
